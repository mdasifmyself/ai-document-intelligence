## What this run revealed, and the fix made

| Finding | Root cause | Fix |
|---|---|---|
| 2 wrong totals, 1 line-item error and 1 PDF-vs-PDF conflict not flagged | rounding allowance grew with the amount (0.1%), so large BDT amounts hid differences | allowance is now 2 cents + 0.5 cent per line, never a percentage |
| Duplicate flag on the first of two identical ledger rows | the flag went to whichever row was processed second | flag goes to the later copy (upload time, then row order) |
| One ambiguous date (03/04/2026) resolved by the model's guess | the model's reading was accepted when it gave a value | any ambiguous printed date is left empty and flagged |
| 4 OCR documents with a missing/unproven key value | self-check re-read only ran on maths problems | self-check also runs when key values are missing or unproven on OCR pages |
| 5 unreadable photos counted as "false flags" | they were labelled "no issues expected" | relabelled: unreadable scans are expected to go to review (READ_FROM_IMAGE) |
